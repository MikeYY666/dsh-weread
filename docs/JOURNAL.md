# 今日与回顾：首版产品与数据设计

日期：2026-11-05。对应 0.3.0 版本，延续现有书架、统计与读书墙。

## 产品目标

让用户打开插件时看到今天留下的内容，并重新遇见过去的划线和想法。无需数据库、独立服务或额外的模型配置。

## 页面结构

导航：今日 / 书架 / 回顾 / 统计 / 读书墙。今日为默认入口。

今日包含：日期、阅读／收听总时长、个人划线与想法数量、今天翻开的电子书、今日笔记列表。有当天划线时突出呈现「今日划下的一句」，没有时回退到「旧句重逢」。读过的书可进入插件详情或跳回微信读书。无阅读、无笔记与接口失败分别处理；失败不显示为零。

回顾包含：按月查看的笔记日历、日期选择、划线／想法筛选、书名／作者／内容搜索、当日笔记，以及往年同月同日的「那年今日」。笔记和旧句均展示封面、书名、作者及章节，点击封面或书名进入详情；复用缓存中的封面地址，缺图时显示占位。没有周年笔记时用过去的划线做「旧句重逢」。原文直接引用，保留书名、章节与日期，不生成或改写金句。

「今日／回顾」共用一份加载状态和一次宿主同步。切换标签或进入详情保留页面状态；刷新页面、退出再进入、重启 dsh 都优先读取宿主保存的笔记。默认每 24 小时自动更新一次，有缓存时不再显示首次扫描进度；过期同步期间仍保留原有笔记。

## 数据口径

- 阅读／收听时长：`/readdata/detail` 月度 `readTimes` 中当日分桶。不是每本书当天的阅读时长。
- 今天翻开的书：真实书架 `/shelf/sync` 中 `readUpdateTime` 为今天的电子书。不使用笔记本 `sort` 代替阅读时间，不包含文章入口和专辑。
- 划线与想法：`/user/notebooks` 枚举有笔记的书，再获取每本书的个人划线与全部个人想法。按内容创建日期归档，不声称还原历史阅读流水。
- 同一条划线与附带想法是两种内容；显示各自数量，不使用含书签的「总笔记数」统计口径替代。
- 日期使用浏览器本地日历，原始统计分桶遵循微信读书上游。异地时区可能存在日期边界差异。
- 每次打开或主动刷新今日时，先从符合日期条件的书籍中均匀随机选一本，再随机选取其中一句个人划线；当天有划线时仍优先使用当天候选。首次展示后固定原文，后台同步和候选变化不会自动换句。「换一句」从当前书的缓存划线中切换，「换一本」从全部缓存划线中按书轮换，确保避开当前书；没有其他书时禁用。选句操作本身不触发笔记同步。

- 句子与「回到原文」使用微信读书原生 `bestbookmark` 链接，依据上游 `chapterUid` 和 `range` 定位。旧缓存缺少位置时，点击后通过 `/journal-note-link` 仅补查单书划线并按账号缓存 24 小时；缺失位置时明确退回打开书籍，已删除划线报错。切换句子会取消尚未完成的跳转。

## 无数据库的数据流

浏览器只查询 `GET /api/weread/journal-cache`。有缓存时一次请求即可显示笔记；没有缓存或已过期时由宿主启动唯一的后台同步，页面只在同步进行时查询进度。「今日／回顾」共用同一订阅。`POST` 同一路径用于用户主动立即同步。

宿主每轮同步只取一份笔记本概览，比较各书的划线数、想法／评论数和笔记更新时间。数量及时间未变化时复用该书已缓存内容；只对新增或变化书籍按每批 6 本、最多 2 本并发获取详情。已移出笔记本的书从新缓存中移除。校验信息与整份笔记保存在同一个 JSON 文件，按 bookId 复用内容，不重复存储两份笔记。

同步工作不依赖页面是否打开。返回 `JournalCacheState`：notes、totalBooks、scannedBooks、failedBooks、syncing、updatedAt、error、hasCache。成功缓存 24 小时内不再自动访问笔记上游；超过 24 小时先返回已有内容，再后台增量检查。同步失败保留上次成功的笔记及校验信息，用户可主动重试。

JSON 缓存在宿主配置旁的 `journal-cache/` 目录，以 API Key 的 SHA-256 摘要隔离账号；浏览器不会拿到 API Key 或存储身份。缓存目录权限 700、文件权限 600，临时文件原子替换避免写到一半损坏。首轮同步每 30 秒保存检查点，重启后可接着整理。修改凭证会重置前端共享状态，宿主在请求前后检查账号，避免在途同步混入另一账号的数据。不使用数据库或浏览器持久化存储。

保留原来的 `/journal-notes` 分页接口作兼容，但新页面不再逐批调用它。

## 首版边界

- 书籍多时首次全量获取需要时间；界面显示覆盖进度，加载中或失败时所有内容只代表已加载范围。
- 不保存回顾反馈、新写想法、每日阅读快照，也不承诺离线浏览。
- 不提供历史每日完整书单、单书当日时长或当天阅读章节区间，这些信息现有接口不能可靠直接还原。
- 暂不加入 AI 每日小结、主题串读或阅读习惯评价；首版确保真实摘录与日期回顾可用。
